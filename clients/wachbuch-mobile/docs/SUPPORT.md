# Wachbuch – Support

**App:** Wachbuch für iOS und Android  
**Quellcode:** https://github.com/Katschko-IT/Wachbuch-Client

## Hilfe

Wachbuch ist ein Open-Source-Client für selbst gehostete Wachbuch-Server. Bei Problemen zuerst prüfen:

1. Der Server ist per HTTPS erreichbar.
2. Die Serveradresse zeigt auf einen Wachbuch-Server mit kompatibler `/api/v1/`-Schnittstelle.
3. App-Token beziehungsweise Zugangsdaten gehören zum richtigen Server.
4. Bei MFA wird ein im Wachbuch-Web erzeugter App-Token verwendet.
5. Kamera- und Standortberechtigungen sind optional; Serveradressen können manuell eingegeben werden und das Design funktioniert ohne Standortberechtigung.

## Fehler melden

Technische Fehler des mobilen Clients können öffentlich gemeldet werden:

https://github.com/Katschko-IT/Wachbuch-Client/issues

Bitte keine Passwörter, App-Tokens, internen Serveradressen, Patienten-, Einsatz- oder personenbezogenen Organisationsdaten in öffentliche Issues kopieren.

## Server-Support

Für Benutzerkonten, Datenlöschung, Rollen, Backups, Serverbetrieb oder organisationsinterne Inhalte ist der Betreiber des jeweils verbundenen Wachbuch-Servers zuständig.

## Sicherheitsmeldungen

Sicherheitsrelevante Meldungen sollten keine ausnutzbaren Geheimnisse oder personenbezogenen Daten in einem öffentlichen Issue enthalten. Verwenden Sie, sofern für das Repository aktiviert, GitHubs private Security-Advisory-/Security-Reporting-Funktion.

## Produktgrenze

Wachbuch ist kein Notruf-, Alarmierungs-, Einsatzleit-, Patientenakten- oder ePCR-System und keine offizielle Behörden-App. Bei einem Notfall sind die hierfür vorgesehenen offiziellen Kommunikations- und Notrufwege zu verwenden.

# English

Wachbuch is an open-source client for self-hosted Wachbuch servers. Mobile-client issues can be reported at:

https://github.com/Katschko-IT/Wachbuch-Client/issues

Never post passwords, app tokens, private server addresses, patient data, incident data or personal organisational data in a public issue. Account management, deletion requests, backups and server-side data are the responsibility of the operator of the server you connected to.

Wachbuch is not an emergency-calling, dispatch, alarm, patient-record or ePCR application and is not an official government app.
