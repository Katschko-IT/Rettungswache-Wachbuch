# Sicherheit

Sicherheitslücken bitte vertraulich an die Maintainer melden – nicht öffentlich
in Issues mit Tokens, `.env` oder personenbezogenen Daten.

Der Client speichert das API-Token in der plattformüblichen Secure Storage
(Keychain / Keystore). Server-URL liegt in Shared Preferences.

Siehe auch die Security-Policy des Server-Repos:
https://github.com/Katschko-IT/Rettungswache-Wachbuch/blob/main/SECURITY.md
