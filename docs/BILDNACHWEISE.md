# Bildnachweise

Hintergrundbilder des Terminal-Sperrbildschirms (`core/static/core/lockscreen/`).
Quelle: Wikimedia Commons. Für den Sperrbildschirm mittig auf 16:9 zugeschnitten,
auf 1280×720 verkleinert und leicht weichgezeichnet (`scripts/build_lockscreen_backgrounds.py`).
Bearbeitete Bilder unter CC BY-SA stehen weiter unter derselben Lizenz.
Auf dem Sperrbildschirm steht der Nachweis des jeweils gezeigten Bildes.

## App-Icon

Das kursive „W“ im App-Icon (`core/static/core/icons/`, `site/assets/favicon.svg`,
App-Icons des Flutter-Clients) ist die Glyphe aus **Inter Display SemiBold Italic**
von Rasmus Andersson, lizenziert unter der SIL Open Font License 1.1
(https://github.com/rsms/inter). Sie ist als Vektorpfad in `scripts/make_app_icons.py`
hinterlegt; die Schrift selbst wird nicht mitgeliefert.
