{% translate "Aufbau" %}

{% translate "Alle Teile laufen als Docker-Container auf einem Rechner: einem Mini-PC oder Raspberry Pi in der Wache oder einem Server bei euch. Es gibt keine Cloud dahinter, keinen Anbieter-Zugang und kein Nach-Hause-Telefonieren." %}

  • {% translate "Caddy liefert HTTPS mit eigenem Zertifikat; Datenbank und Zwischenspeicher haben keinen Port nach außen." %}
  • {% translate "Alle Skripte und Schriften kommen vom eigenen Server, ohne CDN; eine strenge Content-Security-Policy verbietet Inline-Skripte." %}
  • {% translate "Externe Dienste wie Wetter, Verkehrslage, Müllkalender, Signal oder Push sind aus, bis die Wache sie einschaltet." %}

{% translate "Welche Daten gespeichert werden – und welche nicht" %}

{% translate "Gespeichert" %}

  • {% translate "Konten: Name, Benutzername, Rolle je Wache, optional ein kleines Profilbild." %}
  • {% translate "Wachalltag: Übergaben, Mängel, Aufgaben, Checklisten und Termine mit Zeitstempel und Autor." %}
  • {% translate "Fachmodule: Fahrzeuge, Medizingeräte mit Prüffristen, Material mit Beständen und Verfall." %}
  • {% translate "Kaffeekasse: Beiträge und Zahlungen der Teilnehmenden." %}
  • {% translate "Audit-Log: wer wann was geändert hat – mit Feldnamen und Statuswerten, ohne Freitexte." %}
  • {% translate "Freiwillig und widerrufbar: Geburtstag (Tag und Monat), Signal-Nummer." %}

{% translate "Bewusst nicht" %}

  • {% translate "Keine Patienten-, Einsatz-, Alarmierungs- oder Diagnosedaten – das Übergabeformular weist ausdrücklich darauf hin." %}
  • {% translate "Keine Dienstpläne und keine Leistungs- oder Lesestatistiken über Personen." %}
  • {% translate "Keine Analyse-Dienste, keine Werbe-Cookies, keine Telemetrie – nur technisch notwendige Cookies." %}
  • {% translate "Keine beliebigen Datei-Uploads: Anhänge nur in erlaubten Formaten und Größen; Fotos zu Mängeln werden ohne Metadaten (z. B. GPS) neu gespeichert." %}

{% translate "Schutz und Zugriff" %}

{% translate "Anmeldung" %}{% translate "Persönliche Konten statt Sammel-Login. Passwörter mit Argon2id, Zwei-Faktor-Anmeldung (TOTP) und Passkeys; Anmeldeversuche werden gedrosselt." %}
{% translate "Rollen" %}{% translate "Master-Admin, Schichtleitung, Kassenwart, Mitglied und Auditor – jeweils pro Wache. Jede Abfrage ist an die eigene Wache gebunden; Auditoren sehen keine Freitexte." %}
{% translate "Verschlüsselung" %}{% translate "Transport per HTTPS. Zwei-Faktor-Geheimnisse liegen mit AES-256-GCM verschlüsselt in der Datenbank. Chat, Privatnachrichten und Post werden im Browser Ende-zu-Ende verschlüsselt (AES-256-GCM, ECDH P-256): Datenbank und Backups enthalten nur Chiffretext. Der ausgelieferte Webclient und der Server bleiben dabei Teil des Vertrauensmodells." %}
{% translate "Nachvollziehbarkeit" %}{% translate "Audit-Log, Kaffeekasse, Checklisten-Abschlüsse und Übergabe-Versionen sind nur anfügbar: Korrekturen entstehen als neue Einträge, nichts wird still überschrieben." %}
{% translate "Touch-Terminal" %}{% translate "Das gemeinsame Terminal öffnet mit dem Wachen-Code nur den Alltagsmodus – keine Medizingeräte, keine Fahrzeugübernahme, keine Verwaltung. Es funktioniert nur an registrierten Geräten." %}
