{% translate "3. In fünf Schritten startklar" %}

  1. {% translate "Rechner vorbereiten" %}

    {% translate "Docker installieren (Anleitung auf docs.docker.com). Für den Internet-Weg vorher beim Domain-Anbieter einen A-Eintrag auf die IP-Adresse des Servers anlegen, z. B. wache.example.org." %}

    {% translate "Für den Raspberry Pi in der Wache gibt es ein eigenes Skript, das zusätzlich WLAN, Zertifikat und Touch-Terminal einrichtet – siehe „Raspberry Pi“ weiter unten." %}

  2. {% translate "Installer starten" %}

    {% translate "Im Terminal des Rechners eingeben. Wer das Skript vorher lesen möchte, lädt es zuerst herunter:" %}

    curl -fsSLO https://raw.githubusercontent.com/Katschko-IT/Rettungswache-Wachbuch/main/install.sh
less install.sh
sudo sh install.sh

  3. {% translate "Fragen des Installers beantworten" %}

    {% translate "Name der Wache und Betriebsart: „local“ (nur dieser Rechner), „lan“ (im Netz der Wache) oder „domain“ (im Internet mit eigener Domain). Der Installer prüft alles, erzeugt sämtliche Schlüssel und zeigt am Ende die Adresse und den Einrichtungscode." %}

  4. {% translate "Wache einrichten" %}

    {% translate "Die angezeigte Adresse im Browser öffnen, den Einrichtungscode eingeben und dem Assistenten folgen: Name und Anschrift, eigenes Admin-Konto, Impressum und Datenschutz, Zwei-Faktor-Anmeldung, Module." %}

  5. {% translate "Team einladen und absichern" %}

    {% translate "Kolleginnen und Kollegen per Einladungslink oder QR-Code einladen. Die Datei .env im Installationsordner auf den USB-Stick kopieren und sicher verwahren – ohne sie sind Datenbank und Backups nicht mehr lesbar. Dann automatische Updates einschalten:" %}

    sudo /opt/wachbuch/wachbuch auto-update an

{% translate "Raspberry Pi in der Wache" %}

{% translate "Raspberry Pi OS (64 Bit, mit Desktop) auf die SSD schreiben, den Pi einmal per Kabel ans Internet hängen und dann:" %}

git clone https://github.com/Katschko-IT/Rettungswache-Wachbuch.git
cd Rettungswache-Wachbuch
sudo WLAN_SSID="Wachwerk RW1" deploy/pi/setup-pi.sh
sudo reboot

{% translate "Nach dem Neustart öffnet der Touch-Bildschirm direkt die Ersteinrichtung. Das Skript spannt ein eigenes WLAN auf, erzeugt ein Zertifikat und zeigt den Einrichtungscode an. Ausführlich mit Abhak-Liste:" %} docs/PI-WACHENTERMINAL.md

{% translate "Im Alltag" %}

{% translate "Alle Befehle laufen im Installationsordner, unter Linux /opt/wachbuch:" %}

wachbuch status{% translate "Läuft alles?" %}
wachbuch update{% translate "Neue Version holen – vorher wird automatisch gesichert." %}
wachbuch backup{% translate "Sofort ein Backup anlegen." %}

{% translate "Der Browser warnt vor dem Zertifikat (Betriebsart „lan“)." %}

{% translate "Ich habe den Einrichtungscode nicht mehr." %}

{% translate "Der Installer meldet einen belegten Port." %}

{% translate "Ein anderes Programm nutzt den Port bereits, oft ein Webserver. Entweder das Programm beenden oder den Installer mit einem anderen Port starten, z. B. „sudo sh install.sh --port 8091“." %}

{% translate "Meist zeigt der DNS-Eintrag noch nicht auf den Server oder die Ports 80 und 443 sind in der Firewall geschlossen. DNS-Änderungen brauchen manchmal einige Minuten." %}
